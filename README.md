# OFFGRID AI

An offline-first AI assistant for iOS and Android. Once set up, it works with
no internet, cellular service, or cloud. Emergency preparedness is its first
specialty.

**Status:** Milestone 1 (Flutter foundation) is complete. See
[docs/roadmap.md](docs/roadmap.md).

```bash
flutter pub get
dart run build_runner build
flutter test
flutter run
```
